# How to Write an Argumentative Essay

**An interactive English writing course built with Articulate Storyline 360.** The opening screen introduces the experience as *Building a Strong Argument: From Ideas to Essay Outline*.

**[Launch the public course](https://yuanbo-liu.github.io/argumentative-essay-course/)** · [Direct player link](https://yuanbo-liu.github.io/argumentative-essay-course/story.html)

The [launch page](index.html) automatically redirects to `story.html` and provides a manual fallback link.

## Project context and learners

Designed for **Chinese non-English-major college students**, the course guides learners from analysing an argumentative essay to creating their own outline. A worked example, **“Is Big Data a Good Thing?”**, introduces the structure; practice activities use **“Is smart technology making us dumb?”**

The published course includes an introduction, learning objectives, explanations, guided practice and a final self-check. See the [course description](meta.xml) and [About This Course slide](html5/data/js/5Z3pzXy7BRg.js).

## Interaction design

- **Explore a worked example:** clickable components reveal explanations and examples of introduction elements, supporting points and refutation.
- **Practise with feedback:** multiple-choice, multiple-response and drag-and-drop activities include correct/incorrect feedback and retry options. Selected questions explain the reasoning.
- **Choose an alternative interaction:** the drag-and-drop task links to a [keyboard-accessible alternative](html5/data/js/5zIEgXeg2f2.js). This is a specific design feature, not a claim of full accessibility compliance.
- **Draft and reflect:** text-entry prompts, sample responses, a model outline and clickable checklist support independent practice. Open-ended writing is reviewed through examples and self-checking.
